# Dependabot Security Demo

This is a simple Python project created to demonstrate how to configure Dependabot for automated security updates.

## Project Overview

This repository contains:

- A `requirements.txt` file with Python dependencies
- A `.github/dependabot.yml` configuration file
- Dependabot configured to check for dependency updates weekly

## Dependencies Used

- fastapi
- requests
- pandas

## Dependabot Configuration

Dependabot is configured to:

- Monitor pip dependencies
- Check for updates weekly
- Use "deps" as the commit message prefix

## Purpose

This project demonstrates automated security update management using GitHub Dependabot.
